# Yati\n\n## Overview\nA frontend JavaScript project configured with extensive deployment configurations mapping to Netlify and Firebase environments. It houses structural setup scripts manipulating `.js` files indicating heavy custom build or refactor steps.\n\n## Key Configurations\n- `firebase.json` & `firestore.rules`: Logic mapped to Firebase hosting / database rules.\n- `netlify.toml`: Continuous deployment workflow setups targeting Netlify pipelines.\n- `package.json`: Contains primary scripts running the codebase.\n\n## Utility Scripts\n- `cleanup_logs.js`\n- `move_structure.js` / `move_files.bat`\n- `refactor_imports.js`\n- `restructure.js`\n- `update_imports.js`\n\n## Getting Started\n1. Run Node Package Manager index:\n   ```bash\n   npm install\n   ```\n2. For testing/building, utilize defined scripts located within scripts array inside `package.json`. Make sure you run relevant refactor steps initially if building from a raw branch.\n
